# YSP 5.2.2 发布与外部验收总结

日期：2026-11-17（Asia/Shanghai）

## 版本内容

- 完整主账本备份导入前校验重复商品内部 ID、财务及其他必要集合，避免不完整文件静默覆盖现有账本。
- 导入每日备份时恢复其历史操作日志并标记为“来自备份”；备份历史不参与本机未同步操作判断、回溯和销售回滚。
- 界面说明明确区分手动备份与每日备份所含日志，并说明导入替换范围。
- 税务提醒补齐 2027 年季度表及 2027 年度经营所得 B 表；预估截止日期明确标注待官方校准。
- 版本号升至 5.2.2。

## 发布前验证

- `npm test`：53 个测试文件、424 项通过。
- `npm run build`：生产构建成功；仍有 ExcelJS 压缩后约 929 KB、gzip 后约 256 KB 的代码块大小警告，不影响构建完成。

## 外部验收

- 独立 Supabase 项目：双隔离登录会话同步、修订号竞争、冲突选择、失败重试及账号权限验证完成。临时项目与组织按用户确认删除；详情见 `docs/superpowers/reports/2026-11-17-supabase-qa.md`。
- 完整备份：隔离 Chrome 中的手动备份导出/导入、刷新恢复、日志回填与保护失败演练完成；原始 JSON 未改写。
- car 历史档案：旧 car 页面和 YSP 档案页面逐项核对。10-19 ¥15 与 10-22 ¥21 同 SID 销售为迁移前后重复记录；未改数据，数量、成本和账户余额基准一致。估值空值规则差异已记录。
- Excel 打印：桌面 Excel 使用 Adobe PDF 实测。A4 全工作簿 37 页；A3 期间入库清单 125 条、2 页，续页重复明细表头，页码及横向纸张尺寸正确。实际实体打印未做。

## 未覆盖项

本次列明的外部环境验收范围已经完成，但不把整个风险计划夸大为全部通过。仍未完成实体纸张抽印、第二台物理设备/真实手机验证、强制结束浏览器进程、税务机关 2027 正式期限核对、BIZ-01～BIZ-04 全链路 UI 验收及本次发布后的线上冒烟。
