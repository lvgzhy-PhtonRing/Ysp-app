# 数据说明页面（Data Help Page）设计

日期：2026-10-14
状态：已获用户确认，待实现

## 目标

在程序中新增一个「数据说明」入口，向用户展示两篇文章：
1. 数据储存位置说明（数据存在哪里）
2. 数据丢失恢复指南（丢了怎么办）

纯说明性静态内容，不改动任何数据逻辑。

## 入口与交互

- 侧边栏底部「导出备份 / 导入数据 / 云端同步 / 操作日志」四个按钮，整合为：
  - 「数据操作」上级按钮 → 点击展开二级菜单：导入数据 / 导出备份 / 数据说明
  - 「云端同步」「操作日志」保持原样独立按钮
- 点击「数据说明」→ 弹出 `GlassModal`，展示文章，风格与「操作日志」弹窗一致

## 组件改动

| 文件 | 改动 |
|---|---|
| `src/components/AppSidebar.vue` | 底部按钮重构：新增「数据操作」可展开二级菜单；新增 `help` 事件 |
| `src/components/DataHelpModal.vue`（新建） | 用 `GlassModal` 承载文章内容，两部分：储存位置 / 恢复指南 |
| `src/App.vue` | 引入 `DataHelpModal`，加 `showDataHelp` 状态，接侧边栏 `@help` 事件并渲染弹窗 |

## 文章内容要点

**一、数据储存位置**
- 三个存放处：本机浏览器（`ysp_data` 主数据 / `ysp_ui` 界面状态 / `ysp_adopt_before` 回朔点）、Supabase 云端单行（覆盖式）、本机 Downloads 每日 JSON
- 四类数据在哪对照表
- 要点：云端无历史版本、快照无上限、回朔点 1MB/20 条、撤销栈不持久化

**二、数据丢失恢复指南**
- 三样东西分工：主数据=当下数据、回朔点=短时后悔药、Downloads=唯一体外备份
- 丢失场景对照表（云端被覆盖 / 浏览器清空 / 换设备 / 导入搞砸 / 找回历史）
- 操作步骤（导出 / 导入 / 数据回溯 / 云端同步）
- 重要提醒：回朔点和主数据都在浏览器里，建议每日导出备份到网盘/U盘
