# 美淘记录栏目 UI 优化设计

## 概述

优化美淘记录（rushcar）模块的3个方面：侧边栏颜色统一、页面布局重构（高频查询优先）、账号管理默认只读视图。

## 一、侧边栏颜色改灰

**文件**：`src/components/AppSidebar.vue`

**改动**：`getTabStyle()` 函数中移除 `rushcar` 的特化颜色分支，回归默认灰色样式。`payton` 保持蓝色特殊处理不变。

- 未选中：`color:#0f766e` → `color:#4b5563`
- 选中：`background:#ecfeff;color:#0f766e;` → `background:#eff6ff;color:#0066cc;`

## 二、历史记录页面重构

### 2.1 Tab 改名

- "美淘购买信息记录" → "历史记录"
- 新增第三个 Tab "录入记录"（备用入口，与弹窗内的表单内容一致）

### 2.2 历史记录为主视图

原4组输入表单从页面移除，页面顶部仅保留：
- 标题行 + "新增美淘记录"按钮
- 过滤栏（用户名/支付卡/收件人三个下拉，保持现状）
- 历史记录主表格（占据核心视野）

### 2.3 宽屏弹窗录入

点击"新增美淘记录"按钮 → 弹出 Modal（`max-w-6xl`，约 1152px）：

弹窗内垂直排列4组输入：
1. **订单基本信息**：购买组下拉 + 日期/网站/账户(只读) + 商品表格
2. **操作环境信息**：设备/虚拟机/网络/VPN/浏览器 横向 grid
3. **网站登录信息**：用户名(只读) + 收件人 + 转运公司/账号(只读)
4. **付款信息**：持有人/卡片/Shop快捷/金额/实际扣款/备注 + 保存按钮

弹窗底部：取消 + 保存美淘记录按钮

### 2.4 "录入记录"第三个 Tab

内容与弹窗完全一致（同一组表单），作为备用入口。当弹窗因某种原因不便时，用户可切换到第三个 Tab 进行录入。

### 2.5 文件改动范围

- `src/modules/rushcar/RushCarPrototypeModule.vue` — 重构 template 布局
- `src/modules/rushcar/useRushCarPrototype.js` — 可能需要暴露弹窗状态

## 三、账号与卡片管理 — 默认只读视图

### 3.1 转运公司信息（A区）

默认展示为只读行（紧凑文本排列），每行显示：

```
[转运公司名称] | [登录用户名] | *** | [收件人名称] | [国内收件人] | [编辑] [删除]
```

- 密码前三位默认显示 `***`，点击眼睛图标切换显示
- 点击"编辑"按钮 → 该行切换为编辑态（input/select 替换文本）
- 新增行默认也是只读（显示 `-` 占位），需手动点编辑

### 3.2 美泰网站信息（B区）

同样默认只读行：

```
[登录用户名] | *** | [收件人列表逗号分隔] | [美泰称呼] | [编辑] [删除]
```

编辑逻辑同转运公司。

### 3.3 关键逻辑改动

- 移除 `forwarderEditableMap` / `mattelEditableMap` 自动进入编辑态
- 新增行 `isEditable` 默认 `false`
- 保留"编辑中"/"已保存"状态 badge

### 3.4 银行卡信息（C区）

保持现状不变。
