# 云端冲突对比菜单设计

日期：2026-10-23

## 目标

用户在决定采用云端或本地前，能先看清两份数据的主要差别，再按需查看具体记录。保持现有逐槽位选择、二次风险提醒及备份语义。

## 现状与选择

现有弹窗默认只露出每类前 2 处差异，数字取整、文本截断，财务结算和 Owner 资金对象又未进入差异列表。仅扩大窗口虽改动少，仍需逐条阅读。采用已确认的“关键数据概览＋可展开明细”方案。

## 界面与数据口径

- 对比区先以“云端 / 本地”双列列出更新时间、商品总件数、库存件数、库存成本合计、已售件数；金额按人民币两位小数显示。计数均来自当前待比较的完整 payload，而非操作日志。
- 每个待决定模块显示双方条数；商品模块加列库存成本。对象模块（财务结算、Owner 资金）不伪装成条数，展示变更字段数。模块下方给出新增、缺失、字段变更的数量，详情可展开。
- 明细按“字段名称：云端值 / 本地值”展示；沿用业务页的中文说法，如状态值 `sold` 显示为“已出售”。成本、售价、销售利润等金额以人民币两位小数显示，价差同时突出；其他小数保留原值，完整文本允许换行。财务结算和 Owner 资金须逐字段展示；无可用差异时明确标注“无法生成明细”，不得声称 0 处差异。
- 双方更新时间仅作线索，不推断哪边数据更全。现有推荐方向和风险二次确认继续工作。顶部明确告知“选择作用于下方列出的模块”。
- 缺失的财务默认零值按 `0` 比较，避免旧数据出现“无 / ¥0.00”的假差异；市价历史与销售售价使用不同中文名称。
- 小屏幕双列内容可横向滚动或改为上下堆叠，不裁掉数据或选择按钮；键盘可操作。

## 范围与验收

只改冲突信息的展示和相关纯计算，不改存储格式、云端协议、选择结果。财务默认零值的规范化也会消除对应的虚假冲突。验证商品数量／库存成本、财务结算与 Owner 资金差异、含小数和长文本的字段，以及当前选择流程；运行现有测试和构建。
