# 跨期到账销售导出设计

## 目标

导出某个销售发生区间时，单独列出已确认但实际到账日在该区间之外的销售，避免其从所选区间的工作簿中完全消失。

## 规则

- 税期仍由实际入账日 `saleDetails.entryDate` 决定；主销售明细、税务参考汇总和补差明细只收录入账日在所选期间内的确认销售。
- 新增“跨期到账销售”工作表：收录符合销售渠道筛选、销售状态为已售、已确认到账、销售日期 `saleDetails.date` 在所选期间内、且有效入账日不在所选期间内的交易。
- 跨期表只作追踪提示，不进入所选期间的合计；交易应归入实际入账日期所在税期。
- 表格不展示下单日期；展示商品、SID、批次、成交金额及费用，并显示实际到账日期和对应税期。
- 导出预览显示跨期笔数，并说明这些记录不计入当前期间合计。
- 未确认交易、缺失/无效入账日继续遵守现有待确认事项逻辑，不猜测到账日期。

## 验收标准

1. 所选销售日期在10月、到账日期在11月的确认交易出现在10月工作簿“跨期到账销售”页，且不进入10月销售明细、补差明细及汇总。
2. 同一交易在11月工作簿按实际入账日出现在主销售明细并计入11月汇总。
3. 其它销售渠道、未确认销售以及销售日期不在所选区间的记录不进入跨期页。
4. 跨期页不展示下单日期，列明实际到账日期和税期。
