# 手机只读查询新版主数据设计

日期：2026-10-31

## 目标

让手机查询页以登录后的只读会话读取 Supabase 私有 `main` 快照，并正确呈现新版 Owner 与销售渠道数据，同时可刷新并看见数据更新时间。主数据继续保持私有，手机页不提供任何写入操作。

## 当前问题

- `public/ysp-remote.html` 以匿名请求筛选 `is_public=true`，与私有 `main` 行及 `cloud-config.json` 的 `publicRead:false` 不匹配。
- 页面忽略 Owner 和 `saleDetails.shop`，全 Owner 的商品混合展示。
- 页面只在加载时获取一次主数据，无法在当前页面刷新主快照，也没有显示主数据时间。
- 主数据迁移逻辑在 `src/data/migrations/index.js`，手机页是独立静态 HTML，不使用该逻辑。
- README 记载的 JSON URL 回退入口并不存在。

## 方案与取舍

1. **推荐并已获大王陛下执行授权：手机页使用 Supabase Auth 同账号登录，获取 JWT 后读取私有 `main`。** 不改变 RLS 或行可见性；仅新增 SELECT 请求。会话只存 `sessionStorage`，退出时清除；页面提供主动刷新。
2. 将 `main` 公开给匿名访问。改动更少，但完整财务、库存成本和销售数据会对任何持有 anon key 的人开放，不采用。
3. 新建仅供手机页读取的脱敏视图/API。暴露数据最少，但需要额外数据库对象和维护路径，本轮不做。

## 页面内容

- 全局 Owner 筛选：Papa、Payton，默认 Papa，与主程序默认 Owner 一致；不提供全局跨 Owner 汇总。
- 销售页提供“当前 Owner / 全部 Owner”范围切换，与主程序销售页一致；全部 Owner 时标明每件商品的 Owner。
- 销售页增加店铺筛选：全部、PhtonRIng、侧空翻棉、其它；展示销售渠道及可选的确认/入账信息（主数据有字段时才显示）。
- 库存列表和商品详情展示 Owner；Payton 长线标为“自留”、短线标为“投资”。
- 首页月度、库存、采购、利润和现金流依当前 Owner 计算，与主程序一致。手机端补上现金流监控，沿用快照、开业日期、月净回款、采购投入及借贷变化规则。
- Payton Owner 下的财务入口切换为只读“皮蛋金库”，展示 Payton 零花收支、Owner 贷款和零钱/投资互转；Papa Owner 下显示公共收支与借贷关系。
- 支付宝计算器按主程序口径：Papa 的销售利润、公共收支、借贷、库存和采购，加共享参数与 Payton 基金；未确认交易沿用共享参数。
- 顶部提供刷新按钮和主快照更新时间；刷新失败时保留已载入内容并提示错误。
- 兼容旧快照：缺失 Owner 按 Papa 处理；缺失销售渠道沿用主程序日期规则：有效销售日期早于 2026-10-15 归“其它”，其余归 PhtonRIng，无效日期归“其它”。

## 安全与范围

- 只在浏览器发送登录、续期、读取和登出请求；不把密码或令牌写入 URL/日志。
- access/refresh token 仅存当前标签页的 `sessionStorage`；不保存用户密码。
- 手机页仅向 `ysp_state` 发 GET，确认没有 POST/PATCH/DELETE。
- 保持 `main` 的私有配置与 RLS，不改云端 SQL、不公开完整数据；基金值直接从同一 `main` 快照里的 `ownerRegistry.payton` 计算，不再旁读 `car` 行。
- 更新 README，使其反映真实登录、只读和刷新行为，删除不存在的 JSON URL 回退说明。

## 验收标准

- 未登录时不能读取 `main`，显示登录界面与清晰错误。
- 正确账号登录后可读私有 `main`；错误账号、超时、网络故障有可恢复提示。
- 刷新会请求最新快照并更新更新时间；刷新失败不清空当前内容。
- Papa/Payton 筛选作用于 Owner 相关页面；销售页另有当前 Owner/全部 Owner 切换；商品查询和批次回款统计维持主程序的跨 Owner 范围。
- 首页支付宝余额与主程序使用相同 Owner 取数和借贷状态过滤；切换 Payton 不改变该计算器的 Papa+Payton 基金口径。
- 销售渠道过滤准确；旧销售缺字段时按主程序迁移规则归类。
- 现金流按当前 Owner 过滤，Payton 开业日前显示空值；近 12 个月与快照债务取值匹配主程序。
- Payton Owner 财务页读取 `ownerRegistry.payton` 的账户、贷款事件与互转记录；Papa Owner 财务页只显示 Papa 公共收支和借贷。
- 令牌只存在 `sessionStorage`，登出清除令牌；手机页没有任何写入操作。
- 支付宝计算器、Payton 基金、跨 Owner 商品查询、批次回款及转运关联的取数和分组逻辑与主程序一致。
