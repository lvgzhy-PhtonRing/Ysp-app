# 跨期到账销售导出实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**目标：** 在所选销售区间工作簿中增加独立跨期页，同时让税务归期和汇总继续严格按实际到账日。

**方案：** 在工作簿数据构建阶段复用渠道筛选与已确认交易，按销售日期识别所选期间内、入账日期在期间外的记录；将其作为独立工作表，不并入主明细与汇总。导出弹窗只补充跨期笔数和口径说明。

**技术：** Vue 3、JavaScript、现有 ExcelJS 工作簿生成器。

**设计：** `docs/superpowers/specs/2026-11-16-cross-period-sales-export.md`

## 全局约束

- 主台账销售与补差仍只按实际入账日期筛选和汇总。
- 跨期页不展示下单日期、不重复计入期间总额。
- 销售渠道筛选继续生效。
- 不改数据结构或销售数据。

## 重点复核

- 已确认销售日期在期间内、入账日期在期间外：只进入跨期页。
- 已确认销售入账日期在期间内：只进入主销售明细和相应汇总。
- 未确认、缺失/无效入账日期：不得猜测税期。
- 销售渠道未勾选：不应进入任何销售页或汇总。
